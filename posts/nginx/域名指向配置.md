## 一、按域名分发到不同服务

### 1.1 创建网络并启动 Nginx

```bash
docker network create nginx-test

docker run --name nginx \
  --network nginx-test -itd \
  -p 80:80 \
  -v ./nginx.conf:/etc/nginx/conf.d/proxy.conf \
  nginx:1.25.1
```

### 1.2 Nginx 配置(双 server 块)

```nginx
# 客户端请求缓冲(大请求体场景)
client_body_buffer_size   2048m;
client_header_buffer_size 2048m;
client_max_body_size      2048m;

# 域名 a.com → 服务 127.0.0.1:5000
server {
    listen      80;
    server_name a.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# 域名 b.com → 服务 gin:8080
server {
    listen      80;
    server_name b.com;

    location / {
        proxy_pass http://gin:8080;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 1.3 启动后端服务

```bash
# 该镜像默认端口 5678,这里容器内重命名为 gin
docker run --network nginx-test -itd \
  --network-alias gin \
  435861851/gin:v0.0.1
```

> 在 nginx 容器内 `curl gin:8080` 应输出 Hello Gin。

### 1.4 配置 hosts 并验证

```bash
# /etc/hosts 添加
127.0.0.1 b.com

# 访问验证
curl http://b.com
# 输出 {"message":"Hello Gin!"}
```

## 二、按 URL 路由分发到不同服务

### 2.1 Nginx 主配置(完整 nginx.conf)

```bash
# 启动命令
docker run -d --name my-nginx \
  -p 80:80 \
  -v ./nginx.conf:/etc/nginx/nginx.conf \
  nginx:1.25.1
```

```nginx
user  nginx;
worker_processes  auto;

error_log  /var/log/nginx/error.log notice;
pid        /var/run/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include      /etc/nginx/mime.types;
    default_type application/octet-stream;

    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for"';

    access_log  /var/log/nginx/access.log main;

    sendfile          on;
    keepalive_timeout 65;

    server {
        listen      80;
        listen      [::]:80;
        server_name localhost;

        error_page 500 502 503 504 /50x.html;

        # /user 路由转发到指定后端
        location /user {
            proxy_pass http://192.168.232.224:9191;
            # proxy_pass http://127.0.0.1:8181;

            # 保留后端返回的 header
            proxy_set_header Host            $host;
            proxy_set_header X-Real-IP       $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

### 2.2 匹配规则说明

| 访问路径 | 命中 location | 转发到 |
|---------|--------------|--------|
| `/user` | `location /user` | `http://192.168.232.224:9191` |
| 其他 | 默认(无匹配) | Nginx 默认行为 |

## 三、完整配置示例

把"按域名"和"按路由"两种模式合并到一个 nginx.conf:

```nginx
user  nginx;
worker_processes  auto;

events {
    worker_connections 1024;
}

http {
    include      /etc/nginx/mime.types;
    default_type application/octet-stream;

    sendfile          on;
    keepalive_timeout 65;

    # ============ 按域名分发 ============
    server {
        listen      80;
        server_name a.com;

        location / {
            proxy_pass http://127.0.0.1:5000;
            proxy_set_header Host              $host;
            proxy_set_header X-Real-IP         $remote_addr;
            proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
    }

    server {
        listen      80;
        server_name b.com;

        # 按路由分发到不同后端
        location /user {
            proxy_pass http://user-service:8080;
            proxy_set_header Host            $host;
            proxy_set_header X-Real-IP       $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }

        location / {
            proxy_pass http://gin:8080;
            proxy_set_header Host              $host;
            proxy_set_header X-Real-IP         $remote_addr;
            proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
    }
}
```

| 请求 | 命中规则 | 转发到 |
|------|---------|--------|
| `Host: a.com` | server a.com | `127.0.0.1:5000` |
| `Host: b.com, /user` | server b.com, location /user | `user-service:8080` |
| `Host: b.com, /api` | server b.com, location / | `gin:8080` |
