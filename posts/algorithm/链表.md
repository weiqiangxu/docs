## 一、基础定义

```go
type ListNode struct {
    Val  int
    Next *ListNode
}

// 双向链表
type DoublyNode struct {
    Val  int
    Prev *DoublyNode
    Next *DoublyNode
}
```

**单链表 vs 双向链表 vs 循环链表**：

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 单链表 | 仅 Next 指针 | 通用、栈/队列实现 |
| 双向链表 | Prev + Next | LRU、双向遍历 |
| 循环链表 | 尾节点指向头 | 约瑟夫问题、轮询 |

## 二、链表构造

```go
// 哨兵节点（dummy head）简化头指针处理
func buildList(arr []int) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    for _, v := range arr {
        cur.Next = &ListNode{Val: v}
        cur = cur.Next
    }
    return dummy.Next
}

// 倒序构建（头插法）
func buildReverse(arr []int) *ListNode {
    var head *ListNode
    for _, v := range arr {
        node := &ListNode{Val: v, Next: head}
        head = node
    }
    return head
}
```

> **哨兵节点（dummy head）**：链表题最重要的技巧。处理头节点可能被删除/修改的情况时，统一逻辑、避免特判。

## 三、反转链表

### 3.1 迭代反转

```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    cur := head
    for cur != nil {
        next := cur.Next
        cur.Next = prev
        prev = cur
        cur = next
    }
    return prev
}
```

### 3.2 递归反转

```go
func reverseListRec(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    newHead := reverseListRec(head.Next)
    head.Next.Next = head // 让下一个节点指向自己
    head.Next = nil       // 断开原方向
    return newHead
}
```

### 3.3 反转区间 [left, right]

```go
// 头插法：把 cur 的下一个节点插到 pre 之后
func reverseBetween(head *ListNode, left, right int) *ListNode {
    dummy := &ListNode{Next: head}
    pre := dummy
    for i := 1; i < left; i++ {
        pre = pre.Next
    }
    cur := pre.Next
    for i := 0; i < right-left; i++ {
        next := cur.Next
        cur.Next = next.Next
        next.Next = pre.Next
        pre.Next = next
    }
    return dummy.Next
}
```

### 3.4 K 个一组反转

```go
func reverseKGroup(head *ListNode, k int) *ListNode {
    dummy := &ListNode{Next: head}
    pre := dummy
    for {
        tail := pre
        for i := 0; i < k; i++ {
            tail = tail.Next
            if tail == nil {
                return dummy.Next // 不足 k 个不反转
            }
        }
        nextGroup := tail.Next
        // 反转 [pre.Next, tail]
        cur := pre.Next
        prev := nextGroup
        for cur != nextGroup {
            nxt := cur.Next
            cur.Next = prev
            prev = cur
            cur = nxt
        }
        // 衔接
        newHead := tail
        newTail := pre.Next
        pre.Next = newHead
        pre = newTail
    }
}
```

## 四、快慢指针

### 4.1 找中点

```go
// 偶数长度时 slow 停在前半段末尾
func middleNode(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    return slow
}
```

### 4.2 删除倒数第 N 个

```go
func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummy := &ListNode{Next: head}
    fast, slow := dummy, dummy
    for i := 0; i < n; i++ {
        fast = fast.Next
    }
    for fast.Next != nil {
        fast = fast.Next
        slow = slow.Next
    }
    slow.Next = slow.Next.Next
    return dummy.Next
}
```

## 五、删除节点

### 5.1 删除给定值

```go
func removeElements(head *ListNode, val int) *ListNode {
    dummy := &ListNode{Next: head}
    cur := dummy
    for cur.Next != nil {
        if cur.Next.Val == val {
            cur.Next = cur.Next.Next
        } else {
            cur = cur.Next
        }
    }
    return dummy.Next
}
```

### 5.2 删除重复元素（已排序）

```go
// 保留一个副本
func deleteDuplicates(head *ListNode) *ListNode {
    cur := head
    for cur != nil && cur.Next != nil {
        if cur.Val == cur.Next.Val {
            cur.Next = cur.Next.Next
        } else {
            cur = cur.Next
        }
    }
    return head
}

// 完全去重
func deleteDuplicatesAll(head *ListNode) *ListNode {
    dummy := &ListNode{Next: head}
    cur := dummy
    for cur.Next != nil && cur.Next.Next != nil {
        if cur.Next.Val == cur.Next.Next.Val {
            val := cur.Next.Val
            for cur.Next != nil && cur.Next.Val == val {
                cur.Next = cur.Next.Next
            }
        } else {
            cur = cur.Next
        }
    }
    return dummy.Next
}
```

## 六、合并链表

### 6.1 合并两个有序链表

```go
func mergeTwoLists(l1, l2 *ListNode) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    for l1 != nil && l2 != nil {
        if l1.Val <= l2.Val {
            cur.Next = l1
            l1 = l1.Next
        } else {
            cur.Next = l2
            l2 = l2.Next
        }
        cur = cur.Next
    }
    if l1 != nil {
        cur.Next = l1
    } else {
        cur.Next = l2
    }
    return dummy.Next
}
```

### 6.2 合并 K 个有序链表

```go
// 小顶堆法：O(N logK)
import "container/heap"

type MinHeap []*ListNode

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].Val < h[j].Val }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)        { *h = append(*h, x.(*ListNode)) }
func (h *MinHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func mergeKLists(lists []*ListNode) *ListNode {
    h := &MinHeap{}
    heap.Init(h)
    for _, l := range lists {
        if l != nil {
            heap.Push(h, l)
        }
    }
    dummy := &ListNode{}
    cur := dummy
    for h.Len() > 0 {
        node := heap.Pop(h).(*ListNode)
        cur.Next = node
        cur = cur.Next
        if node.Next != nil {
            heap.Push(h, node.Next)
        }
    }
    return dummy.Next
}
```

## 七、环形链表

### 7.1 判断是否有环

```go
func hasCycle(head *ListNode) bool {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}
```

### 7.2 找环入口

**推导**：设头到环入口距离 a，环入口到相遇点距离 b，相遇点到环入口距离 c。
- 慢指针走 `a + b`
- 快指针走 `a + b + n(b + c)`，且 = 2 × 慢指针
- 推得 `a = (n-1)(b+c) + c`，即从头走 a 步 = 从相遇点走 a 步会到环入口

```go
func detectCycle(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            // 相遇后，让一个指针从头开始，再次相遇即为环入口
            p := head
            for p != slow {
                p = p.Next
                slow = slow.Next
            }
            return p
        }
    }
    return nil
}
```

## 八、回文链表

```go
 // 找中点 → 反转后半段 → 双指针比较
func isPalindrome(head *ListNode) bool {
    if head == nil || head.Next == nil {
        return true
    }
    // 1. 快慢找中点（前半段末尾）
    slow, fast := head, head
    for fast.Next != nil && fast.Next.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    // 2. 反转后半段
    second := reverse(slow.Next)
    // 3. 对比
    p1, p2 := head, second
    for p2 != nil {
        if p1.Val != p2.Val {
            return false
        }
        p1 = p1.Next
        p2 = p2.Next
    }
    return true
}

func reverse(head *ListNode) *ListNode {
    var prev *ListNode
    for head != nil {
        next := head.Next
        head.Next = prev
        prev = head
        head = next
    }
    return prev
}
```

## 九、LRU 缓存

经典题：`O(1)` get/put。哈希表 + 双向链表。

```go
type entry struct {
    key, val int
    prev, next *entry
}

type LRUCache struct {
    cap        int
    cache      map[int]*entry
    head, tail *entry // 哨兵
}

func Constructor(capacity int) LRUCache {
    head, tail := &entry{}, &entry{}
    head.Next = tail
    tail.Prev = head
    return LRUCache{
        cap:   capacity,
        cache: make(map[int]*entry),
        head:  head,
        tail:  tail,
    }
}

func (c *LRUCache) Get(key int) int {
    if e, ok := c.cache[key]; ok {
        c.moveToFront(e)
        return e.val
    }
    return -1
}

func (c *LRUCache) Put(key, value int) {
    if e, ok := c.cache[key]; ok {
        e.val = value
        c.moveToFront(e)
        return
    }
    e := &entry{key: key, val: value}
    c.cache[key] = e
    c.addToFront(e)
    if len(c.cache) > c.cap {
        removed := c.removeTail()
        delete(c.cache, removed.key)
    }
}

func (c *LRUCache) addToFront(e *entry) {
    e.Next = c.head.Next
    e.Prev = c.head
    c.head.Next.Prev = e
    c.head.Next = e
}

func (c *LRUCache) remove(e *entry) {
    e.Prev.Next = e.Next
    e.Next.Prev = e.Prev
}

func (c *LRUCache) moveToFront(e *entry) {
    c.remove(e)
    c.addToFront(e)
}

func (c *LRUCache) removeTail() *entry {
    e := c.tail.Prev
    c.remove(e)
    return e
}
```

## 十、面试要点

### 10.1 解题套路

| 题型 | 套路 |
|------|------|
| 反转 / 交换 | 迭代三指针 / 递归回溯 |
| 找中点 / 倒数第 N | 快慢指针 |
| 合并 / 排序 | 哨兵 + 双指针 / 归并 |
| 环 | 快慢指针相遇 |
| 回文 | 找中点 + 反转 + 比较 |
| 随机访问 / LRU | 哈希表 + 链表 |

### 10.2 易错点

1. **忘记 dummy**：头节点可能被删/改时，一定要用哨兵
2. **指针丢失**：修改 `cur.Next` 前先保存原 Next
3. **空指针**：访问 `.Next` 前判空
4. **环入口推导**：相遇后从头走 a 步必到入口

### 10.3 高频题清单

- 反转链表 / 反转区间 / K 个一组反转
- 合并两个 / K 个有序链表
- 环形链表 I/II
- 相交链表
- 回文链表
- 删除倒数第 N 个
- 排序链表（归并）
- LRU / LFU 缓存
- 复制带随机指针的链表
